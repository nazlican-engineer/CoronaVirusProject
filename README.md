# COVID-19 Data Analysis

COVID-19 deaths and vaccinations data üzerinde temel SQL analizleri.

## İçerik

- `covid.sql`: Sıralama, veri seçimi ve vaka/ölüm oranı analiz sorguları

## Beklenen tablolar

Sorgular aşağıdaki tabloların veritabanında bulunduğunu varsayar:

- `CovidDeaths`
- `CovidVaccinations`

Ham Excel/CSV dosyaları repoya eklenmez. Verileri yerel veritabanına aktardıktan sonra `covid.sql` içindeki sorgular çalıştırılabilir.
