# Vaka analizi görsel düzeni

Sayfa, kıta, ülke ve haftalık zaman aralığı seçicileriyle filtrelenir.

1. Kümülatif vaka alan grafiği: toplam vakanın tarih içindeki birikimini gösterir.
2. Yeni vaka zaman çizgisi: günlük toplam `new_cases` değerini gösterir.
3. Ülke sıralaması: seçili bağlamda dönemlik yeni vakayı karşılaştırır.
4. Doldurulmuş dünya haritası: ülkeleri dönemlik yeni vakaya göre renklendirir.

Harita için açık pembe–koyu bordo renkleri kullanılır. Tooltip, ülke üzerindeki dönemlik yeni vaka değerini gösterir.
