# Ölüm Haritası Ölçeği

Harita, toplam ölüm yerine `Milyon kişi başına ölüm` ile boyanır. Böylece nüfusu büyük ülkeler otomatik olarak baskın görünmez.

| Ölüm / 1M kişi | Renk | Anlam |
| --- | --- | --- |
| 0–500 | `#F3D9DC` | Düşük kayıtlı ölüm yükü |
| 500–2K | `#D98A96` | Orta düşük yük |
| 2K–4K | `#A8324A` | Yüksek yük |
| 4K+ | `#5C0A14` | Çok yüksek yük |

Harita açıklamasında birim açıkça `ölüm / 1M kişi` olarak belirtilmelidir. Koşullu renklendirme `Dönemlik Yeni Vaka` değil, `Milyon kişi başına ölüm` alanına bağlanır.
