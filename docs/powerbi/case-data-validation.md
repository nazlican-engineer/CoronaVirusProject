# Vaka verisi doğrulama notları

- Kaynak tarih aralığı: 2020-01-01 – 2024-08-14.
- `location` ve `date` birleşimi tekrar içermemelidir.
- `new_cases` boş olan günler eksik veri olarak izlenir; sıfır değerler eksik veri değildir.
- Günlük görselde bazı kaynak kayıtları haftalık/toplu bildirim nedeniyle belirgin sıçramalar oluşturabilir.
- Harita renkleri ülke düzeyindeki dönemlik yeni vaka sayısına göre yorumlanır.
