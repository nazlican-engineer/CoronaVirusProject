# Ölüm Sayfası Tasarımı

Ölüm Analizi, Vaka Analizi'nden görsel olarak ayrışmak için koyu bordo temayı kullanır.

| Kullanım | Renk |
| --- | --- |
| Ana vurgu | `#5C0A14` |
| Aktif gezinme düğmesi | `#E3162A` |
| Sayfa zemini | `#FFF8F6` |
| Kart zemini | `#FFFFFF` |
| Kart ve görsel kenarlığı | `#EBCFD0` |
| İkincil metin | `#806166` |

Kart başlıkları kısa tutulur. Bildirilen ölüm oranı, doğrulanmış enfeksiyon riskini değil, bildirilen ölüm / bildirilen vaka oranını ifade eder; test ve raporlama farklarından etkilenir.
